# Materi Gentsuki — Sumber Pusat

Basis materi resmi Gentsuki untuk ujian SIM 原付 (原動機付自転車) di Jepang. Isinya diolah dari buku persiapan ujian 原付 (157 halaman: aturan lalu lintas, buku hlm. 4–78, plus 8 tryout × 48 soal, buku hlm. 80–159).

## Isi
| File | Isi | Dipakai untuk |
|---|---|---|
| [01-materi-inti.md](01-materi-inti.md) | Semua aturan per bab (A Dasar, B Cara melewati jalan, C Aturan penting, D Berkendara aman) dalam Bahasa Indonesia, plus istilah Jepang | Modul kelas, e-book, skrip video |
| [02-cheatsheet-angka.md](02-cheatsheet-angka.md) | Semua angka yang wajib dihafal dalam tabel | Lead magnet gratis, poster, story IG |
| [03-jebakan-soal.md](03-jebakan-soal.md) | Pola jebakan dan pasangan yang sering tertukar | Konten harian, sesi review sebelum ujian |
| [04-bank-soal.md](04-bank-soal.md) | 384 soal ○/× (8 tryout) beserta jawaban dan alasan | Kuis, tryout berbayar, latihan grup |

## Catatan
- Soal di 04 sudah diparafrasekan. Jangan menyebar scan atau terjemahan buku secara utuh, karena bukunya berhak cipta. Buat soal latihan sendiri dari aturan di 01–03.
- Aturan bisa berubah (contoh: 特定小型原付 sejak 2023). Cek ulang ke 警察庁 atau 試験場 setempat sebelum merilis materi berbayar.
- Persyaratan dokumen untuk WNA (住民票, 在留カード) dan bahasa ujian berbeda per prefektur. Tambahkan info prefektur target di file terpisah bila perlu.
